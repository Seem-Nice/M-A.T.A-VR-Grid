03 / LEARNING NOTES

LOCATION TRACKER

Learn how to identify an object's location using a reference point and grid.

Reference Point

A reference point is a given object or place used to help us identify another object's location.

Read the Grid

Always identify the letter first, followed by the number.

B4

Column B, Row 4.

Horizontal

Move from left to right, or right to left.

A → B → C

Vertical

Move from bottom to top, or top to bottom.

04 / IRIS SYSTEM ALERT

⚠ ERROR ALERT

Stop! Check these common mistakes before completing your mission.

ERROR 01 — WRONG DIRECTION

Do not confuse left with right or up with down. Check the direction before moving.

ERROR 02 — WRONG REFERENCE POINT

Always begin with the reference point given in the question. Do not choose another object.

ERROR 03 — WRONG GRID READING

Do not reverse the order. Read the letter first, then the number. For example, B4 is not 4B.

IRIS REMINDER

Observe carefully. Check the letter. Check the number. Then confirm your answer.
